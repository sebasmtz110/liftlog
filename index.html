Help & Support

How do I log a set?

From the workout, tap Log Set. Minus and plus change the highlighted value, and the keypad does the same. The first digit replaces the number. Bodyweight exercises such as the pull-up log as BW until you add load. Other exercises need a weight above zero.

Can I cut the rest short?

Skip Rest ends it immediately. Closing the rest screen returns you to the set while the clock keeps running on the ring. It is based on the time you started, so leaving the screen does not slow it down. When it reaches zero you come back to the workout.

How does movement connect?

The stage is marked with data-muse-slot="exercise-motion" and data-exercise-id. Set window.ALDER_MOTION_MOUNT to a function and it is called with that element so Muse can mount there. The page also emits alder:motion with the exercise, phase, time, and duration as the playhead moves.
